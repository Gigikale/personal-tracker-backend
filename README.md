# Personal Tracker Backend

This is the backend service for the **Personal Tracker** application — a financial tracking system that helps users monitor their monthly expenses, set spending targets, and analyze financial habits.

Built with **Java Spring Boot** and **PostgreSQL**, the backend exposes a set of RESTful APIs to manage expenses, monthly budgets, and summary reports.

---

## 🚀 Features

- ✅ Add, update, delete expense records
- 📅 Filter expenses by category and date
- 🎯 Set and track monthly spending targets
- 📊 Generate monthly target summaries with target vs. actual spending
- 📦 PostgreSQL support with Docker for consistent development
- 🔄 RESTful API integration for frontend consumption
- 🔐 Clean architecture with proper validation and error handling

---

## 🔧 Technologies Used

- **Java 17**
- **Spring Boot 3**
- **Spring Data JPA**
- **PostgreSQL** (via Docker Compose)
- **Lombok**
- **Maven**
- **Docker / Docker Compose**
